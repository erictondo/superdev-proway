Sobre o SuperDEV

O SuperDEV é uma formação voltada a desenvolvimento de software, passando por tecnologias de front-end e back-end.

Nesta etapa estamos aprendendo a utilizar HTML para estruturar páginas WEB.

  • Python
  • Banco de dados
